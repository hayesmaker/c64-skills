### c64-skills

- A C64 skills toolkit designed for ultra efficient AI C64 game and app development.

# features:

- c64-ready - the first win for llm's developpment and testing of C64 games. Tell the LLM to use c64-ready, my open source, lightweight and feature rich headless browser based c64 emulator and debugger.
- c64-ready is open sourced on github (https://github.com/hayesmaker/c64-ready), and can be cloned locally by llms to use for c64 development and debugging.
- c64-ready can output screenshots, as well as video.

# goal:

- I have found c64-ready to be immensely useful in developing my own c64 games, and would like to share it with others via an installable skill.
- This skill should be easily findable and importable by users wanting to optimise their c64 AI assisted game and app development.
